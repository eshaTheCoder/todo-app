# Todo App - Python 📝

A clean and simple Todo application built with Python, focusing on core programming concepts.

### ✨ Features
- Add, View, Delete Tasks
- Mark Task as Complete
- Task Due Date with `datetime` module
- Data Persistence using `json` file
- Clean Code with OOPs Principles

### 🛠️ Tech Stack
- Language: Python 3
- Concepts: OOPs, File Handling, JSON, datetime
- Tools: Virtual Environment (env)

### 🚀 How to Run Locally
```bash
# 1. Clone the repository
git clone https://github.com/eshaTheCoder/todo-app.git

# 2. Go to folder
cd todo-app

# 3. Create & Activate virtual env
python -m venv env
env/Scripts/activate.bat

# 4. Run the app
python main.py
